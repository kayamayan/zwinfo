# zwinfo

비공식 **Zombie Waves** 정보 아카이브.

공략, 패치 소식, 쿠폰, 도감을 공개된 출처와 함께 모읍니다.
Fun Formula / 北京欢乐扬帆科技有限公司와 무관한 팬메이드입니다.

## 로컬에서 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:8080` (또는 터미널에 찍힌 주소)로 엽니다.

## 구성

| 경로 | 내용 |
| --- | --- |
| `/` | 홈, 활성 쿠폰, 커뮤니티 펄스 |
| `/guides` | 공략 |
| `/news` | 공식 소식 + Reddit 커뮤니티 |
| `/codes` | 쿠폰 (GameRant 공개 목록을 주기적으로 확인) |
| `/codex` | 영웅·무기·로봇 도감 |
| `/sources` | 출처와 가져오지 않는 경로 |

라이브 데이터는 서버에서 가져와 짧은 TTL로 캐시합니다. 라이브 확인이 실패하면 스냅샷으로 대체합니다.

## 주의

- 공식 앱이 아닙니다.
- 쿠폰은 계정당 1회이며, 대소문자를 그대로 입력하세요.
- Discord 비공개 채널 등 비공개 소스는 수집하지 않습니다.
